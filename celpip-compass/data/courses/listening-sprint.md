# Listening Sprint

> **用法：** 倒数第 4 天读 P0 + P1。倒数第 2 天再扫一次 P0。
> **状态：** P0 为 hypothesis。待真实定时模考后替换。
> **前提：** 你日常对话听得懂，瓶颈是 **distractor 识别 + 笔记策略 + conflicting info 分栏**。

## P0 — 必读（10 分钟，5 条）

### P0-1. 每个 Part 播放前 5-10 秒，扫题干知道要听什么

- **失败：** 音频响了才低头看题，前 10 秒信息没听进去。
- **扣分点：** CELPIP 关键信息经常在对话前 10-15 秒出现（speaker 介绍背景）。错过开头后面推不回来。
- **立刻怎么办：** 每次听力开始 5-10 秒前（系统有短暂 pause），快速扫题干。不看 options，只看题问什么：
  - 问 `why` → 听原因连接词 (`because / since / due to`)
  - 问 `what did X do` → 听 X 相关的动词
  - 问 `how many / when / where` → 听数字/时间/地点
- 扫完 4 题题干，音频开始就知道自己是"听原因"还是"听数字"。

### P0-2. 主动笔记：只记转折 + 数字 + 人名 + 负面词

- **失败：** 想记全部 → 记不过来 → 半路放弃 → 后半段信息丢失。
- **扣分点：** Part 5/6 不能重听。错过就是错过。
- **立刻怎么办：** 笔记规则：
  - **转折词**：`but / however / actually / instead / on the other hand` → 听到就在笔记上画个箭头或圈。转折后的内容经常是答案（见 P0-3）。
  - **数字/时间**：`3 days / next Monday / $400` → 直接速记数字
  - **人名/地点**：只记人的第一音节（Sarah → S）
  - **负面词**：`not / don't / can't / without / unable` → 圈一下，否定逻辑是 distractor 常考点
- **不记完整句**。只记这四类信号。

### P0-3. Distractor 最常见型：先说 A，后改 B。答案是 B

- **失败：** 对话里"I was going to take the bus, but I ended up walking." 你记了 "bus"，答题时选 bus → 错。
- **扣分点：** Part 5 高频陷阱。至少 2-3 题用这个套路。
- **立刻怎么办：** 听到以下信号立刻警觉：
  - `but / however / actually / instead / on second thought / I changed my mind / well, no`
  - 转折后说的那个选项才是答案。转折前的是 bait。
- **完整示例：** "Originally the meeting was at 3, **but** we moved it to **4:30 on Thursday**." 答案 = 4:30 Thursday，不是 3。
- **反例子：** 不是每个 but 都是 distractor。只有 but 后是**关键信息替换**时才算。`"It was sunny, but still cold"` 不算。要练耳朵判断。

### P0-4. Part 4（conflicting info）两人对话分两栏记笔记

- **失败：** Part 4 两个人对同一事件观点不同，你笔记写一堆，题问 "according to speaker B"，你分不清哪条是 A 哪条是 B。
- **扣分点：** Part 4 通常 6-8 题，混淆一个 speaker 可能连错 3 题。
- **立刻怎么办：** 音频一开始，草稿纸立刻竖着分两栏：
  ```
  | Speaker A (name?) | Speaker B (name?) |
  |---|---|
  |                   |                   |
  ```
  每次一个人说话，信息记在 ta 的栏里。听到名字立刻填在栏头。**不要混着记。**
- **常考题型：** "What does A think?" / "What does B believe?" / "What do they disagree about?" 分栏后这些题秒选。

### P0-5. 犹豫时跟第一直觉，不改答案

- **失败：** 选了 B，后来想"可能是 A"改成 A，结果 B 才对。
- **扣分点：** CELPIP Listening 不能回听。改答案时你用的是记忆 + 推测，比第一直觉（听音那一刻的判断）弱。
- **立刻怎么办：** 选定后**不要改**，除非你清楚记得听到了某个关键词。犹豫的题圈起来，全部答完再回看 —— 回看时仍然不改，除非有明确证据。
- **证据例子：** "我明确听到 'Thursday'" = 证据。"我感觉可能是 A" = 不是证据。

## P1 — 次要（20 分钟，3 条）

### P1-1. Part 1/2 听两遍，第一遍定答案第二遍验证

- Part 1/2 音频播两遍。第一遍做题，第二遍确认有没有漏细节。
- **不要第一遍完全不选等第二遍** —— 两遍听力 cognitive load 太大，注意力会散。
- 第一遍选 80% 确定的答案；第二遍专注听第一遍不确定的那 1-2 题。

### P1-2. Part 3 新闻报道，听"标题句"和"结尾句"

- 新闻类音频结构固定：开头一句点题 → 中间展开 → 结尾总结/影响/预测。
- 题目答案集中在开头 + 结尾。中间信息只在问 "details" / "why" 时关键。
- 扫题发现题都问 "main idea / conclusion" → 中段可以略松懈，集中听首尾。

### P1-3. Part 6 viewpoints：记立场+论据

- Part 6 是一个人发表观点。记两件事：立场（agree/disagree with X）+ 1-2 个论据（why）。
- 题目常问 "what is the speaker's view" 和 "what example does the speaker use"。立场+论据笔记正好 cover。

## Drills — 崩溃瞬间操练

### Drill: flip-flop

**前后反转**

- **什么样子：** 对话里说"I thought we should meet at 3, but after checking with the team, let's do 4:30." 你笔记写了 "3"，交卷时选 3 pm → 错。
- **为什么扣分：** Distractor 陷阱 #1。
- **立刻怎么办：** 执行 P0-3。听到 `but / however / actually / instead` 立刻在笔记上画箭头 → 把前面的数字划掉，记新的数字。
- **坏笔记：** `meet 3 pm` （记了旧信息）
- **好笔记：** `meet ~~3~~ → 4:30, after team check` （记了转折和新信息）

### Drill: two-speaker-mix

**双人观点混淆**

- **什么样子：** Part 4，A 说"restaurants should ban phones"，B 说"no, phones are fine if silent"。你笔记写了一堆，题问 "What does B think?" 你记不起来哪条是 B 的。
- **为什么扣分：** Part 4 题密度高，一个 speaker 混淆连错 3 题。
- **立刻怎么办：** 执行 P0-4。音频 0 秒时草稿纸就画分栏。笔记必须写在对应栏里，不要在两栏之间或顶部乱写。
- **坏笔记：** 横写一行 "ban phones / fine if silent" —— 不知道谁说的
- **好笔记：**
  ```
  | A (Mike)          | B (Sarah)          |
  | ban phones        | fine if silent     |
  | distract others   | adults control self|
  ```

### Drill: memory-dump

**听完就忘**

- **什么样子：** Part 5 讨论听完，去选答案，发现具体细节忘光了。
- **为什么扣分：** Part 5/6 不能重听。没笔记 = 没答案。
- **立刻怎么办：** 执行 P0-2。音频开始就写。哪怕没听清也写你猜到的第一个词。宁可记错也不要空白。后面还能靠上下文修正。
- **预防：** 模考时强制练"边听边记"。听模考听力时把草稿纸分栏，真考一样操作。肌肉记忆比考场发挥更稳。

### Drill: detail-miss

**细节抓不到**

- **什么样子：** 题问 "How much does it cost?" 音频里说 `"$400 plus tax"`。你笔记没数字，答题时只记得"贵"，选错。
- **为什么扣分：** 数字/时间/地点是 CELPIP 爱考点，每个 Part 至少 1 题。
- **立刻怎么办：** 执行 P0-2 的数字记录规则。耳朵听到 **$ / 数字 / 星期 / 月份 / 城市** 立刻在笔记上抄，不要思考意义，先抄下来。
- **坏笔记：** "貌似要 400 多块" —— 模糊
- **好笔记：** `$400 + tax, Thu` —— 精确

## Rescue Checklists

### Mid-exam-scan（每个 Part 播放前 5-10 秒）

- [ ] 扫过题干，知道这个 Part 要听什么（P0-1）
- [ ] 草稿纸准备好（Part 4 两栏，其他 Part 单栏）
- [ ] 笔在手上，不要等音频响了再找笔

### Post-part-scan（每个 Part 结束后 30 秒）

- [ ] 所有题都选了答案？没空白？（P0-5 不留空）
- [ ] 犹豫的题圈了标记，但**没有改过答案**？（P0-5）
- [ ] 下一 Part 的题干扫过了？

### Pre-submit-scan（交卷前）

- [ ] 答题卡所有题都有 letter？
- [ ] 没有事后"二猜"改过的答案？（第一直觉通常更准）
